¿Qué es una red?
Una red es simplemente un conjunto de dispositivos conectados para compartir información.

Tipos de redes
LAN
Local Area Network.

Ejemplo:
La red de una empresa.

WAN

Conecta varias LAN.

Ejemplo:

Una empresa con oficinas en Santo Domingo, Santiago y Punta Cana.

Internet

La red más grande del mundo.

¿Qué hace un Switch?

El switch conecta dispositivos dentro de la misma red.
El switch no da Internet. Solo conecta equipos entre sí.

¿Qué hace un Router?

El router conecta redes diferentes.

Dirección IP

Cada dispositivo necesita un identificador único.
Es como la dirección de una casa.
Si no tienes dirección, nadie puede enviarte información.

Dirección MAC

La IP puede cambiar.

La MAC no.

Ejemplo:

00:1A:2B:3C:4D:5E

La MAC viene de fábrica con la tarjeta de red.

¿Qué ocurre cuando visitas Google?

Supongamos que escribes:

www.google.com

El proceso, simplificado, es:

El navegador pregunta al servidor DNS cuál es la IP de www.google.com.
El DNS responde con una dirección IP.
Tu PC envía los paquetes hacia esa IP.
El router los dirige hacia Internet.
Google responde.
El navegador muestra la página.

Como analista SOC, deberás entender este flujo para identificar dónde puede estar el problema o el ataque.

Conceptos que debes memorizar
Concepto	Definición
IP	Identifica un dispositivo en la red.
MAC	Identificador físico de la tarjeta de red.
Router	Conecta redes distintas.
Switch	Conecta equipos de la misma red.
LAN	Red local.
WAN	Red de gran alcance.
DNS	Convierte nombres de dominio en direcciones IP.
